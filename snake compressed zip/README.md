# Taffy 贪吃蛇大作战

一个基于 Qt6 开发的贪吃蛇小游戏，塔菲主题。

## 下载 & 游玩

直接下载 [Taffy贪吃蛇大作战.zip](Taffy贪吃蛇大作战.zip)，解压后双击 `snake--button.exe` 即可开始游戏。

无需安装任何数据库或其他依赖，所有文件已打包在内。

## 操作说明

- **W/A/S/D** — 上下左右移动蛇
- **K** — 提前结束游戏
- 菜单按钮可切换难度、查看在线排行榜等

## 系统要求

- Windows 10/11 64位
- 无需额外安装运行时（Qt DLL 已附带）

## 安全说明

- 本游戏不再包含任何数据库连接代码（MySQL 依赖已移除）
- 在线排行榜功能会向服务器发送玩家昵称和分数，不使用请忽略
- 本地高分仅在当前会话中保存，关闭游戏后重置
