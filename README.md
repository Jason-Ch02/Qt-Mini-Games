# 🐍 Qt Snake Game
A classic Snake game built with Qt6 + CMake  
Clean, elegant, smooth-running, and well-structured — perfect for Qt beginners ✨

---

## 🌟 Project Introduction
This is a classic Snake game developed using Qt C++, with project management via CMake. The code is clean, readable, and features complete game logic and smooth interaction.

- Native Qt development, no third-party dependencies
- Cross-platform compatibility (Windows / Linux)
- Clean & beginner-friendly code structure
- Smooth gameplay and standard controls

---

## 🧱 Tech Stack
- **Language**: C++17
- **Framework**: Qt 6 / Qt 5
- **Build Tool**: CMake
- **IDE**: Qt Creator
